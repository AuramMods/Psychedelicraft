# Forge 1.20.1 settings matrix

This companion to [the port report](PORT_1201.md) inventories every leaf of the actual registered Forge config specs: **106 common values and 34 client values**, captured from the packaged cycle-29 runtime. Defaults come from `ForgeConfigSpec.ValueSpec`, rather than a hand-maintained list. Source paths refer to accepted commit `51286f8f3e6866e8b952175c9c60c7f6e63bef8d`, unless marked original (`319a4ea0160d6600cffcd5f5cc9e363ceaab44a1`). Consumer names are relative to `src/main/java/ivorius/psychedelicraft/`.

The evidence column identifies the cycle and shared production path tested; it does not claim every possible override/combination was tested separately. C29 inspects all named brew suppliers and biome profile aliases. C31 adds **Mods → Psychedelicraft → Config**, a native Forge screen binding every one of these 140 values to its actual registered config field. It uses toggles, bounded visual sliders, exact numeric inputs and comma-separated biome selectors, with individual and recursive category resets. Dedicated connections show only the 34 client values and two locally consumed chat flags. Common gameplay fields remain available at the title screen or in a local integrated world. The rift interval displays minutes while preserving partial-minute tick precision; other durations display ticks. Values apply through their existing consumers and save to these same TOML files on leaving the settings tree. Runtime control verification is recorded under cycle 31 in the port report.

Common values are in `config/psychedelicraft-common.toml`. The chat controls are read locally on each client; putting them in the common file does not impose server-side chat policy. Biome selection is baked during server biome modification: restart and explore new chunks after changing generation profiles. Farmer/Harmonium trade-pool switches are also applied during server offer registration and need a restart for changed offers. Existing explicit settings remain intact when defaults change. Client values are in `config/psychedelicraft-client.toml` and are read by the local renderer/audio system.

All eleven generation profiles retain the accepted enabled/included/excluded behavior. The target `morning_glory` profile maps accepted `morningGlories`; the `peyote` profile controls both peyote and agave, and `coca` also controls the additional common-jungle profile. Original included/excluded selectors had an extra `spawnableBiomes` JSON layer; Forge keeps the accepted direct lists. Duration units are game ticks. Each of the fifteen brew families retains four accepted timing fields; flower extract retains the accepted separate distillation duration.

The original `alcInfoKava`, `shadowPixelsPerChunk` and transient disabled `doShadows` fields have no consumers at the pinned original revision (`git grep` finds declarations only). They are not active target settings. Accepted copper-ore generation and the bee-nest/kelp/sweet-berry profile overrides belong to the 1.12 vanilla replacements; native 1.20.1 world generation and datapacks own those systems. These decisions do not add duplicate native-generation controls.

The native gamerule `doSleepDeprivation` is also registered, with default `false`. Its production tick/wake behavior and operator entry point are covered in C2/C22/C27; it is not a Forge TOML leaf.
