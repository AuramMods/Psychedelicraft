## Architecture and migration status

The first cycle replaces the ForgeGradle 3 / Java 8 build and LaunchWrapper coremod with ForgeGradle 6.0.54, Gradle 8.8, Java 17, Forge 47.4.28 and official 1.20.1 mappings. The production jar uses ForgeGradle's `reobfJar`.

Migration is staged. The initial compiled source contains the mushroom effect pipeline. The other legacy source files and resources remain available in the pinned accepted commit and the original modern commit. Their implementations and regression tests still require migration. The accepted branch's 273 tests provide reference coverage for that work.

The drug capability stores the accepted `Drugs` and `drugInfluences` NBT representation and uses Forge's lifecycle and tracking events. Owner and observer snapshots use a direction-restricted SimpleChannel message. The client defers snapshots until the matching player and dimension exist and clears pending snapshots on logout.

The initial renderer uses a standalone modern PostChain for the donor color-rotation program and a Forge camera-angle event. Shader functions come from the original 1.20.1 resources. Other shader phases, weighted hallucination selection and all remaining effects are pending.

Use Minecraft 1.20.1's native vanilla content for the old backports. The mod-specific interactions still need verification. New 1.20.1 worlds are the target.

## Custom mechanics to preserve

- Nicotine restores two saturation points, or four for a cigar.
- Coffee restores one point per cup and has intensity-scaled speed and reduced saturation exhaustion.
- Cocaine restores one point per second, up to double mining speed and the accepted damage modifier.
- Alcohol reduces saturation exhaustion and incoming damage.
- Mushroom targeting avoidance follows overlapping strength. Local random ticks use the accepted two-to-five block sphere and three-to-eighteen extra ticks per game tick.
- Peyote flight spends saturation only during flight, with the accepted doubled curve and one-point-per-second drain limit.
- LSD retains the smooth reach curve with a seven-block maximum bonus.
- Fresh joints stack, partly consumed joints retain wear, coca seeds require soil and refuse stacked placement, and peyote requires sand.
- Coffee cherries roast, and lower hoppers extract only finished drying-table output.

Implementation anchors are `0ac7e92d`, `0d65421b`, `e7fc247b`, `34920e41`, `b730811f`, `897c25c2` and `17ff1350`.

## Background runtime workflow

`tools/qa` launches Linux Java 17 / LWJGL 3 clients inside Docker under Xvfb. Mesa llvmpipe provides OpenGL 4.5. No client window is created on the macOS desktop. Each client receives a separate game directory, muted master volume, windowed mode, unfocused ticking, four-chunk rendering and a 30 FPS cap. Dedicated servers run with `--nogui`.

Build the image and install the official Forge runtime after building the mod with Java 17:

```sh
docker build --platform linux/amd64 -t psychedelicraft-forge-qa:java17 tools/qa
mkdir -p run/production/cycle1/client run/production/cycle1/server
curl --fail --location https://maven.minecraftforge.net/net/minecraftforge/forge/1.20.1-47.4.28/forge-1.20.1-47.4.28-installer.jar --output run/production/cycle1/forge-installer.jar
java -jar run/production/cycle1/forge-installer.jar --installClient run/production/cycle1/client
java -jar run/production/cycle1/forge-installer.jar --installServer run/production/cycle1/server
cp "$HOME/.gradle/caches/forge_gradle/minecraft_repo/versions/1.20.1/version.json" run/production/cycle1/client/versions/1.20.1/1.20.1.json
```

The launcher merges the installed Forge profile with Mojang's vanilla metadata and downloads the required Linux libraries and assets. An existing Fabric Loom asset cache is an optional read-only source, with `PS_QA_ASSETS` available to select a different cache. Missing assets are downloaded into the isolated install. Parallel client downloads use atomic replacement. Forge's module ignore list includes the installed vanilla jar's filename.

Copy the production mod to the server's `mods` directory. Configure only this test server's EULA, world, bind address and port. The cycle-1 server uses port 25601 and a private flat test world. From its directory, launch:

```sh
java -Xmx2G @libraries/net/minecraftforge/forge/1.20.1-47.4.28/unix_args.txt --nogui
```

Launch clients from the repository root in separate terminals:

```sh
sh tools/qa/run-client.sh run/production/cycle1/client run/production/cycle1/game-owner MushroomOwner owner
sh tools/qa/run-client.sh run/production/cycle1/client run/production/cycle1/game-observer MushroomObserver observer
```

Without the temporary cycle probe these clients open the normal title screen. The ignored `run/production/cycle1/probe` fixture drives normal server connections, item use, capability checks and framebuffer sampling. Probe jars and generated runtime data remain outside tracked production source. Logs and screenshots for this cycle are under `run/production/cycle1`.
