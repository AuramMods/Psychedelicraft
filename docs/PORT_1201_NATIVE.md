# Native Minecraft 1.20.1 mappings

The accepted 1.12.2 branch implements modern vanilla features inside the Psychedelicraft namespace. The Forge 1.20.1 target uses Minecraft's native implementations. These are namespace/model/data migrations for **new 1.20.1 worlds**, not aliases or an importer for old 1.12 saves. Keep custom Psychedelicraft wood, machines, crops, fluids and gameplay in the mod namespace.

Source anchors below are relative to `src/main/java/ivorius/psychedelicraft/` at accepted revision `51286f8f3e6866e8b952175c9c60c7f6e63bef8d`. The original modern revision remains `319a4ea0160d6600cffcd5f5cc9e363ceaab44a1`. Native source inspection uses the locally cached mapped **Minecraft 1.20.1** sources; every compile and runtime check uses **Forge 47.4.28**. C32 names refer to methods in `NativeIntegrationGameTests`; earlier evidence is in [the port report](PORT_1201.md).

The table records current evidence and separates tested mod handoffs from delegated native behavior. It does not claim that registering an ID proves every natural acquisition or lifecycle path. The [current registration/asset matrix](PORT_1201_REGISTRY.md) records the complete runtime ID inventory and bounded asset evidence.
